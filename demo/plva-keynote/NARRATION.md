# One-minute narration

Use Play 60s from the beginning for the timed recording. For manual presenting, use four actions: Enter prompt, Run task, Create skill, and Reuse skill. Each action advances its intermediate scenes automatically and pauses for your narration. The demo has no supplied audio so you can speak naturally over it.

| Time | Scene | Say |
| --- | --- | --- |
| 0–8s | Task and prompt | “A customer needs a replacement. We ask PLVA to handle it while keeping their details private.” |
| 8–18s | Start and protection | “Before Astra sees the screen, PLVA replaces sensitive details with tokens. The original values stay on the device.” |
| 18–29s | Form and result | “Astra works with those tokens. The local runtime restores the values in the intended fields and checks the replacement draft.” |
| 29–39s | Skill creation | “The successful workflow becomes a procedure you can inspect, with its steps and source evidence.” |
| 39–50s | New task and changed form | “Now a different customer arrives, and the form changes. A fresh session uses the saved procedure with new inputs.” |
| 50–60s | New result and close | “The procedure carries over. The private records don’t. That’s PLVA: private computer work that becomes reusable knowledge.” |

About 124 spoken words. Leave small pauses around the protection reveal, the skill, and the second result. The screen labels this as a scripted product walkthrough. The narration describes that illustrated product flow; it must not be presented as a recording of an actual integrated agent run.

## Recording

1. Open PLVA-DEMO.html, press R, then F for stage mode.
2. Start recording a 16:9 canvas. Hide the operating system cursor away from the central screen.
3. Press P for the timed sequence, or use Right arrow four times, waiting for each action to finish before starting the next.
4. Stop after the closing scene. Check the final cut is no longer than one minute.
5. For the hackathon's execution evidence, include actual runtime footage or clearly distinguish this scripted illustration. Do not add a Live label or fabricated API receipt.
